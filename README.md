## 🚀 Featured Projects

### 🇮🇳 [Samvidhan AI](https://github.com/Tarutiwari/samvidhan-AI)

**AI-powered RAG application for querying the Constitution of India.**

- 🔹 Retrieval-Augmented Generation (RAG)
- 🔹 Semantic search over constitutional documents
- 🔹 LangChain + Qdrant vector database
- 🔹 HuggingFace embeddings
- 🔹 FastAPI backend
- 🔹 LLM-powered question answering

**Tech:** Python · LangChain · Qdrant · FastAPI · RAG · LLM

- 🔹 Mamba architecture

- 🔹 Multitask prediction
- 🔹 Backtesting and model evaluation

**Tech:** Python · PyTorch · Mamba · Pandas · NumPy · Machine Learning
